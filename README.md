# 羊场管家 · 奶山羊养殖场管理系统

给自家养殖场用的内部管理小程序（移动端网页版，可"添加到手机桌面"当 App 用）。

**存栏到个体档案、产奶按天统计、出入账带账户余额、财务报表直接导出 Excel。**

---

## 一、启动

**最简单：双击 `goat-farm\启动.bat`**（会自己找 Python、用 UTF-8 输出、监听 0.0.0.0、自动开浏览器）。窗口别关，关了服务就停。

```powershell
cd E:\OPENCODE\goat-farm
E:\OPENCODE\.venv\Scripts\python.exe run.py --open
```

浏览器打开 http://127.0.0.1:8770 ，首次登录：

| 账号 | 密码 |
|---|---|
| `admin` | `goat2024` |

> ⚠️ 登录后**立刻**去「我的 → 修改密码」，别用默认密码。
> 也可以在启动前设环境变量覆盖：`$env:GOAT_ADMIN_PASSWORD='你自己定'`

**让手机也能访问**（手机和电脑连同一个 WiFi）：

```powershell
E:\OPENCODE\.venv\Scripts\python.exe run.py --host 0.0.0.0
```

启动时会打印一个 `http://192.168.x.x:8770` 之类的地址，手机浏览器打开即可。

| 参数 | 说明 |
|---|---|
| `--port 9000` | 换端口 |
| `--host 0.0.0.0` | 允许局域网访问（默认只监听本机） |
| `--open` | 启动后自动开浏览器 |
| `--setup` | 只初始化数据库，不起服务 |
| `--db D:\path\farm.db` | 指定数据库文件位置 |

## 二、六个模块

| 模块 | 干什么 |
|---|---|
| **看板** | 存栏头数、今日产量、本月利润、账户余额、待办提醒，一屏看完 |
| **羊只** | 每只羊一张档案：耳标号、母父编号、出生日期、栋舍、首次产羔日期；事件记录里可以称重、防疫、配种、产羔、转出、死亡。产羔时可直接给羔羊建档，母羊会自动转成"经产泌乳" |
| **存栏** | 当前存栏（分组矩阵 + 栋舍分布）、动态变化（30/90/180/365 天曲线 + 变动明细）、日龄结构（附结构诊断）、饲养预警（待配种 / 产羔临近 / 待断奶 / 久未称重 / 种公羊不足） |
| **产奶** | 快捷录入、产量分析（按日/周/月趋势、批次结构、月度对比）、明细台账 |
| **记账** | 流水（按月翻页）、账户余额（资金 / 应收 / 应付）、收支分析（逐月柱状图）、科目管理 |
| **报表** | 利润表（环比 + 逐月盈亏）、现金流量表、资产负债简表、科目汇总、经营分析（奶业 / 成本结构 / 头均效益） |

### 导出 Excel

报表页和「我的」页都有导出按钮，导出 6 张表：

| 表 | 内容 |
|---|---|
| 经营月报（合并） | 一个工作簿 3 个 sheet：资产负债简表、现金流量表、利润表 |
| 经营年报（合并） | 同上，区间为全年 |
| 利润表 | 收入/成本明细、汇总、利润率、本月逐日 |

| 产奶明细 | 逐日产量、单产、按批次汇总 |
| 存栏档案 | 全部羊只档案 + 事件流水 |

## 三、记账口径（这里最容易出错，先说清楚）

系统把"动钱"和"动利润"分成两件事，用**科目类型**区分：

| 类别 | 例子 | 是否进利润表 |
|---|---|---|
| 经营收支 | 卖奶、精饲料、人工、兽药、租金 | ✅ 进 |
| 往来款 | 赊销记应收、收回应收、还应付 | ❌ 只动余额 |
| 资金往来 | 内部对转、提取现金、借款、还款、股东投入 | ❌ 只动余额 |

**赊销的正确录法**（两步，别录成一步）：

1. 客户赊了 5000 元奶款 → 账户选「应收账款」，科目选「卖奶收入」，方向**收入**。
   这样利润表确认了 5000 元收入，但钱没到账。
2. 客户回款时 → 分两笔：
   - 账户「应收账款」+ 科目「应收收回」+ **支出** 5000
   - 账户「银行账户」+ 科目「应收收回」+ **收入** 5000

这样利润不会重复计，现金也不会凭空多。

**卖羊不用手工记钱**：在羊只详情页记一次"售出"事件填金额，系统会自动生成一条「卖羊收入」流水挂到银行账户上，且这条流水不允许直接删（避免账实不符）。

**内部对转**（银行转微信、取现金到保险柜）用「账户余额」页的对转功能，不要手工记两笔。

### 财务报表的口径说明

| 报表 | 口径 |
|---|---|
| 利润表 | 权责发生制：按科目归集经营收支，往来款/资金往来不进 |
| 现金流量表 | 实收实付，只算资金账户（现金/银行/微信/支付宝），剔除内部对转和提取现金这类"钱换个口袋"的动作 |
| 资产负债简表 | 存栏按购入成本估值（自繁羔羊按 0），往来款按实收实付 |

> 资产负债简表**不强行配平**「资产 = 负债 + 权益」。只有从建账第一天每笔业务都录进系统，这个等式才会自然成立；中途开始用就会出现缺口，那样硬报出来反而误导。所以只报净资产（资产 − 负债）和累计经营利润。
>
> 这些都是**管理用简表**，不是法定财务报表，报税、贷款请以正式报表为准。

## 四、权限

| 角色 | 能干什么 |
|---|---|
| 管理员 | 全部 |
| 场长 | 除系统管理外全部（含报表、财务） |

## 五、数据在哪

整个系统的数据都在**一个文件**里：

```
E:\OPENCODE\goat-farm\data\farm.db
```

用 SQLite（WAL 模式，3-10 人同时录入没问题）。

**备份 = 复制这个文件**。建议每周备份一次，放到另一个目录或网盘：

```powershell
Copy-Item E:\OPENCODE\goat-farm\data\farm.db E:\备份\farm_2026-10-18.db
```

注意：Windows 上直接复制正在使用的 SQLite 文件可能拷到半个事务。稳妥做法是先关掉服务再拷，或用 sqlite3 的 `.backup` 命令。

**换机器 / 换数据目录**：用 `--db` 参数指定，或用环境变量 `GOAT_DATA_DIR`。

## 七、离线与断网

养殖场信号差是常态，这块专门做了处理：

| 场景 | 表现 |
|---|---|
| 有信号 | 正常用，页面资源走本地缓存，二次打开基本秒开 |
| 没信号，只想看数据 | 能打开页面，显示的是**上次联网时**的数据，会提示"当前离线，页面显示的是上次保存的数据" |
| 没信号，要记一笔 | 照常点保存，**不会报错也不会丢**：记录存到本机队列，顶栏显示"离线 · 待传 N"，走回有信号的地方**自动补传**，传完提示"已上传离线记录 N 条" |
| 补传时发现数据已冲突 | 服务端拒绝的那几条会单独提示"请重新录入"，不会静默吞掉 |

补传的几条规则：成功的和"服务端明确拒绝"的出队；`5xx` 和断网的留着下次重试；**登录过期的整队保留**，不会把数据丢掉，提示重新登录后再试。

> **一个重要限制**：浏览器规定 Service Worker 只能在 HTTPS 或 localhost 下注册。所以
> - 电脑本机（127.0.0.1）：全部生效，包括离线打开页面、缓存接口数据
> - 手机走局域网 HTTP（192.168.x.x）：**离线写入队列仍然生效**（纯 JS，不依赖 SW），但"离线打开页面"和"缓存接口数据"不生效
>
> 想让手机也有完整的离线体验，需要把服务部署到 HTTPS 域名上（买域名 + 免费 SSL + 一台常开的机器）。

## 八、目录结构

```
goat-farm/
├── run.py                     启动入口
├── requirements.txt
├── smoke_test.py              端到端冒烟测试（100 项）
├── tools/

│   └── make_icons.py          生成 PWA 图标 PNG（iOS 不认 SVG）
├── data/
│   └── farm.db                数据库（首次启动自动创建）
└── app/
    ├── main.py                FastAPI 应用、异常处理、路由挂载
    ├── db.py                  连接与事务（每线程一连接，WAL）
    ├── schema.sql             表结构

    ├── deps.py                current_user / require 依赖

        ├── index.html         含启动闪屏、离线徽标、SW 注册
        ├── sw.js              Service Worker：离线缓存 + 接口缓存
        ├── manifest.webmanifest
        ├── icon-192/512.png   桌面图标（PNG，iOS 认这个）
        ├── apple-touch-icon.png
        ├── css/app.css
        └── js/                core.js + views/*.js（按需加载）
```
